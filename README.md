# shop.ayushacharya | Premium Agency Store

An interactive, premium single-page digital agency store designed for fine-tuning project scopes, web hosting tiers, and domain extensions in real-time. Built with native performance and a fluid user interface to optimize the order-request sequence.

## 🚀 Features

- **Dynamic Budget Scaling:** Smooth range-sliders allowing clients to scale development and graphic design budgets instantly.
- **Tier-Based Step Sliders:** Real-time feature matrix breakdowns for:
  - **Premium Web Hosting:** (Web Essential, Plus, Pro, Ultimate) matching specific RAM, storage, and performance benchmarks.
  - **Domain Registration:** Dynamic pricing and feature inclusions across 8 top-level extensions (`.xyz`, `.com`, `.net`, etc.).
- **Live Cart Ledger:** Responsive sidebar checkout panel that dynamically aggregates costs and structures order items.
- **Asynchronous Order Dispatch:** Fully integrated with EmailJS for structured client notifications and seamless order lodging.
- **Clean Architecture:** Lightweight, dependency-free vanilla CSS and JavaScript code structure built for lightning-fast loading benchmarks.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Variables, Flexbox/Grid Engine), JavaScript (Vanilla ES6)
- **Icons & Fonts:** FontAwesome Pro, Google Fonts (Plus Jakarta Sans)
- **Backend Integration:** EmailJS API for client-to-agency communications
